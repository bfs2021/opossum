> [!WARNING]
> **Two things in a file that 0.46.0 started are read differently now.**
>
> A name written in `environment:` with no value (`- FOO`, or `FOO:`) now takes its value from the project's `.env` when the shell does not set it, as docker compose does; 0.46.0 passed it unset. If the container should not see that value, remove the name from `environment:`, or write out the value you want.
>
> A healthcheck with `interval: 0s` now probes every 30 seconds, as docker compose reads `0s`; 0.46.0 probed with no wait between, so an `up` that waits on it with `condition: service_healthy` can take about 30 seconds longer (7 seconds became 33 for a service ready after 4). Write the interval you want, such as `interval: 1s`.
