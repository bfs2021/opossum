> [!WARNING]
> **Some files that 0.45.0 started are refused now.**
>
> A `pid: service:<name>` or `ipc: service:<name>` is now a dependency of the service, as in docker compose. A file where it names a service the file does not define now stops `up`, `ps` and `config`: define that service, or remove the `pid` or `ipc`. A file where it closes a dependency cycle (`a` has `pid: service:b` and `b` has `depends_on: [a]`) now stops `up`: remove the `depends_on` or the `pid` that closes the loop.
>
> A network's `attachable`, `enable_ipv4` or `enable_ipv6` whose value is not a boolean (a word such as `maybe`, a number such as `1`, a list, a mapping, or nothing after the key) now stops `up` and `config`: write `true` or `false`.
>
> A project already running from such a file is taken down by a plain `opossum down`. That `down` leaves the networks the file declares, so once the value is corrected, run `opossum down` again to remove them.
